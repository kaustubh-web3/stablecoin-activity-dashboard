# Stablecoin Activity Dashboard

## Overview

This project analyzes stablecoin activity using Dune Analytics and SQL.

The dashboard focuses on:

- Daily Stablecoin Transfer Volume
- Daily Number of Transfers
- Daily Active Users
- Top Stablecoins by Transfer Volume
- Stablecoin Market Share
